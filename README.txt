# For Ritika — Premium Cinematic Crush Website

A mobile-first, single-page HTML/CSS/JS website for a respectful secret-crush confession.

## Run it
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in any modern browser.
3. For editing, use any code editor (on mobile, an HTML editor app works too).

## Customize
- Change the name in `index.html`.
- Change the confession text in the final section.
- Change the three memory-card messages.
- No backend, database, or account is required.
- The Google Fonts connection is optional; the site still works with fallback fonts if offline.

## Privacy / respect
There is no tracking, form submission, forced answer, or hidden data collection. The response buttons only show local messages on the page.
